# 🔎Página de Perguntas Frequentes

A Página de Perguntas Frequentes (FAQ) apresenta dúvidas comuns e suas respectivas respostas, organizadas de forma simples para facilitar o acesso às informações.

## Tecnologias utilizadas

- HTML
- CSS

## Desenvolvimento

Projeto desenvolvido individualmente, com orientação e apoio do professor.
